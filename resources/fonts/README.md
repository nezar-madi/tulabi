# Fonts for PDF files

`Tajawal-Regular.ttf` and `Tajawal-Bold.ttf` are used by the PDF receipts (mPDF needs TrueType
files). Tajawal is the body font, licensed under the SIL Open Font License 1.1.

Copied from rqmana (Arabic and Latin subsets merged into one file per weight). Persian and
Urdu letters (for example پ چ ژ گ) are not in the subset; mPDF substitutes DejaVu Sans for those.
